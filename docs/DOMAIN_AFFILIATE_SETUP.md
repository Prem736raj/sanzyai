# Domain Registrar Affiliate Marketing Setup Guide

## 1. Is Domain Affiliate Marketing Really Possible?

**Yes, 100%.** Domain affiliate marketing is one of the oldest, highest-volume, and most reliable monetization models on the web.

Every time an entrepreneur, developer, creator, or small business builds a project, they need a domain name. Because domain name registrars operate at high search volume and high purchase intent, major registrars offer lucrative affiliate and partner programs.

### How You Get Paid
1. **Per-Sale Bounty / Percentage**: 
   - New domain registrations earn between 10% and 35% commission.
   - Domain transfers earn flat bounties ($2–$10).
   - Bundled hosting, professional email (Google Workspace / Microsoft 365), and SSL certificates generate $20 to $100+ per conversion.
2. **Cookie Duration**:
   - Tracking cookies typically last **30 to 90 days**. If someone clicks your link today to compare prices and purchases 3 weeks later, you still get credited.
3. **SEO & Legal Compliance**:
   - Google and FTC guidelines mandate that paid referral links include `rel="noopener sponsored"`. SanzyAI's link builder automatically enforces this across all registrar links.

## 3. How to Plug In Your Affiliate IDs in SanzyAI

All affiliate configuration is centralized in a single file:
👉 [`src/domain-affiliates.js`](file:///c:/Users/prem7/Downloads/sanzyai-main-20261016T152129Z-1-001/sanzyai-main/sanzyai-main/src/domain-affiliates.js)

### Step-by-Step Instructions:

1. **Open `src/domain-affiliates.js`**.
2. Locate the registrar you want to activate (e.g. `namecheap`):
   ```javascript
   namecheap: {
       name: 'Namecheap',
       network: 'Impact',
       programUrl: 'https://app.impact.com/campaign-promo-signup/Namecheap.brand',
       affiliateId: 'YOUR_IMPACT_OR_AFF_ID_HERE', // <-- Put your ID here
       paramName: 'aff',
       customUrlTemplate: '',
       enabled: true
   },
   ```
3. If using an affiliate network redirect wrapper (like Impact's `pxf.io` tracking link):
   ```javascript
   customUrlTemplate: 'https://namecheap.pxf.io/c/YOUR_ID/12345/6789?u={destination}'
   ```
4. Save the file.
5. Build and deploy:
   ```bash
   npm run build
   ```
Now, whenever visitors search for a domain on SanzyAI and click **"Register →"**, **"Register at Namecheap →"**, or **"Get This Deal →"**, they are routed through your affiliate tracker with `rel="noopener sponsored"`.
